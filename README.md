# Kode.ma

Site IPTV Maroc Premium pour la marque **Kode** (`https://kode.ma`).

## Stack

- Next.js 15 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4

## Développement

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Notes

- Numéro WhatsApp : modifier `WHATSAPP_NUMBER` dans `src/lib/constants.ts`
- Architecture & SEO : basées sur le masterplan (pages, priorités sitemap, métadonnées FR)
